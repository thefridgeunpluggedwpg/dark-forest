# Licenses & credits — Dark Forest v0.2

## Code & art
All code and all pixel art (tiles, trees, huts, walls, mansion, Thronglets, vampires, bats, props, particles)
is original and generated procedurally at runtime in `js/art.js` / `js/render2d.js`. No third‑party art packs are used.
three.js has been removed entirely.

## Optional user art
If `assets/thronglet.png` / `assets/stefan.png` exist they are drawn instead of the procedural sprites (owner-supplied).

## Style references
`ref/style-target.png` and `ref/style-mansion.gif` are client-provided visual references only; they are not shipped as game assets.

## 83 Kingsway
The in-game house (`js/kingsway.js`) is original procedural pixel art modelled on the client references
`ref/mansion-target.jpg` and `ref/mansion-pixel-target.jpg`. The client's pixel image is shipped as `assets/kingsway.jpg`
and used only as the loading splash and the 83 Kingsway inspector portrait (client-supplied, used with permission).

## Character art (v0.4)
assets/thronglet.png (Ian) and assets/stefan.png (Stefan) and their LOD variants are derived from client-supplied originals (ref/ian-thronglet-src.png, ref/stefan-src.png): background removed and cropped only. Used with client permission; not covered by the code license.
